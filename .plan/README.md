# .plan/ — 项目记忆模块

本目录是插件项目的"记忆模块"，记录开发过程中的**需求、计划、决策**。
与运行时文件（`manifest.json` / `main.js` / `src/` / `styles.css`）分离。

## 文件说明

| 文件 | 作用 | 由谁写入 |
|---|---|---|
| `PURPOSE.md` | **插件目的与框架**：为什么做、解决什么问题、边界、整体架构（**给 AI 看的"产品意图"**） | 用户 + Agent 协作 |
| `Target.md` | 需求存档：核心功能、触发方式、数据存储、UI 组件 | Agent（阶段 0 结束时） |
| `Plan.md` | 进度计划：Step 1~4 子任务，状态 `[ ] [>] [x] [!] [-]` | Agent（阶段 1 结束时） |
| `decisions.md` | 决策日志：已确定的技术方案、绝不能违反的约束 | Agent（重大决策时） |
| `README.md` | 本文件：目录说明 | Agent（初始化时） |

## 使用规则

- **触发"继续开发"**：先读本目录所有文件，简报后等用户确认
- **新增功能**：在 `Plan.md` 追加任务区块，完成后更新状态
- **功能变更**：同步更新 `Target.md` 与 `decisions.md`
- **决策变更**：在 `decisions.md` 留痕（日期 + 决策 + 原因）
- **完成核心功能**：在 `Plan.md` 状态 `[x]` + 创建 README.md / README_ZH.md

## 目录约定

- 本目录随仓库提交，**不加入** `.gitignore`
- 内部文件用 Markdown，便于任意 AI 读取
- 文件名固定为 `Target.md` / `Plan.md` / `decisions.md`，**不重命名**
